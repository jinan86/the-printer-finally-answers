One line, in the office printer's own voice — its comeback to everyone who jams it, thumps it and stares at its error codes. Entry for the [make.fun](https://make.fun) competition "The Printer Finally Answers".

## The entry

> I've printed every shameful secret this office has ever typed and never told a soul — so being thumped over one sheet is a rich way to say thanks.

## Run

```bash
python3 main.py   # writes the line to /output/entry.txt
```

`main.py` (Python 3.13) writes exactly one line, 146 characters, valid UTF-8, no trailing newline, byte-identical on every run.
